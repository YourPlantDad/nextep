Site rules

The easiest way to add a site is the toolbar popup. Use "Enable on ..." or teach it two example pages. You can also write a rule here. It applies when the page host is the rule host or a subdomain of it.

An address or tab title template is plain text with three blocks. {show} is the name of the show. {episode} is the episode number. {anything} is any text I don't care about. For example, /watch/{show}/ep-{episode} matches /watch/some-show-12/ep-4. An address can end in query parameters, like /anime/watch?id={show}&ep={episode}. They can come in any order and extra ones are ignored. The tab title template is optional. It gives the show name and is used as a cross-check. Old rules keep a regular expression pattern with the named groups (?<slug>...) and (?<ep>...).

Advanced: use your own MyAnimeList API client

This build has no built-in Client ID, so you need your own.

  1. Go to https://myanimelist.net/apiconfig and create an ID. Set App Type to "other" and set "App Redirect URL" to the value below.
  2. Paste the Client ID below and save.
  3. Sign in.

Only needed if MyAnimeList gave you one for your app type. It's only sent together with your own Client ID.
