Sign in to MyAnimeList

On sites you enable, NextEp searches MyAnimeList for the show name from the episode page, and reads and updates your list under your own sign-in. Nothing goes to me. Privacy policy

Signing in means you accept this privacy policy.

Site rules

You can enable a site from the toolbar popup ("Enable on ...") or add a rule here. A rule applies when the page host is the rule host or a subdomain of it. The pattern is a regular expression tested against the path plus query string. It needs the named groups (?<slug>...) and (?<ep>...).

Advanced: use your own MyAnimeList API client

This build has no built-in Client ID, so you need your own.

  1. Go to https://myanimelist.net/apiconfig and create an ID. Set App Type to "other" and set "App Redirect URL" to the value below.
  2. Paste the Client ID below and save.
  3. Sign in.

Only needed if MyAnimeList gave you one for your app type. It's only sent together with your own Client ID.
