Site rules

The easiest way to add a website is the toolbar popup. Use "Enable on ..." or teach it two example pages. You can also write a rule here. It applies when the page's website is the rule's website or a subdomain of it.

An address or tab title template is plain text with three blocks. {show} is the name of the show. {episode} is the episode number. {anything} matches any text. For example, /watch/{show}/ep-{episode} matches /watch/some-show-12/ep-4. An address can end in query parameters, like /anime/watch?id={show}&ep={episode}. They can come in any order and extra ones are ignored. The tab title template is optional. It gives the show name and is used as a cross-check.
